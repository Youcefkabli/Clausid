# Qualification evidence

No new deployment is qualified by the verification foundation. Copy the
[qualification template](../templates/qualification.md) for a named candidate and target.
Record exact revision, environment/configuration identifiers without secrets, CI/local evidence,
two-account workflow, recovered artifact digest, remaining checks, owner and final decision.

Keep local, CI, staging, production and recovery results distinct. A green CI run or matching
supplied manifest is not a completed hosted or recovery rehearsal. Store sensitive artifacts in
restricted evidence storage and link only non-sensitive identifiers here.
